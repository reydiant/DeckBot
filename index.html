Lock screen buttons

This page can't sit on your iPhone lock screen, but a Shortcut can. Each lock-screen tap writes a line to a log file. Import that file here and the taps land in your counts with their real times.

Importing the same file again is safe. Lines already counted are skipped. You can also import a CSV exported from the Claude version to bring your history over.

Set up the shortcuts (iOS 18 or later)
  1. Open Shortcuts, tap +, and name the shortcut Bucket +1.
  2. Add Format Date. Set Date to Current Date, Date Format to ISO 8601, and turn on Include Time.
  3. Add Text. Type BUCKET, a space, then insert the Formatted Date variable.
  4. Add Append to Text File. Point it at bucket-log.txt in the Shortcuts folder of iCloud Drive and turn on Make New Line.
  5. Duplicate the shortcut twice. Name one Reset timer with RESET as the text, and one Pause with PAUSE. Each Pause tap switches between paused and running.
  6. Press and hold your lock screen, tap Customize, then Lock Screen. Tap the – on a bottom button, tap the empty spot, choose Shortcut and pick Bucket +1. Put Reset timer or Pause on the other side. Add the third one to Control Center the same way.
  7. Back in this app, tap Import lock-screen log and pick bucket-log.txt from iCloud Drive › Shortcuts.

Your iPhone may ask for Face ID before a shortcut can write to the file.

minutes

A bucket that took longer than this (not counting paused time) still counts, but stays out of your average times. It catches the times you forgot to pause.
